# GenAI-langchain-chatbot-project

# 🤖 GenAI Chatbot using LangChain & OpenAI

A beginner-friendly Generative AI chatbot built using **LangChain** and **OpenAI GPT models**. This project demonstrates how to integrate Large Language Models (LLMs) into Python applications using the LangChain framework.

---

## 🚀 Project Overview

This project is part of my AI Engineering learning journey, where I explore enterprise AI application development using LangChain.

The chatbot accepts natural language prompts from users and generates intelligent responses using OpenAI's GPT models.
